# Match Lab — マッチングアプリ会話シミュレーター

プロフィール一覧から相手を選び、自分の好みカード（興味タグ）との共通点を使って会話を進めるブラウザアプリです。

## 主な機能
- WITHの「好みカード」「プロフィール一覧」を参考にした相手探しUI
- 女性プロフィール（年齢、居住地、職業、性格、経歴、興味タグ）
- 自分の興味タグ設定と共通点の可視化
- いいね・マッチング・メッセージの会話シミュレーション
- 通話モードと話題選択による盛り上がり判定
- 初回デート打診・確約
- プロフィール理解、初回メッセージ、会話継続、通話、初回デートの段階別進捗表示

## 起動
GitHub Pagesで公開する場合は、Settings → Pages → Deploy from a branch → main / root を選択してください。ビルド不要の静的サイトです。

## データと確率について
現状はブラウザ内のデモデータと仮想スコアで動作します。表示確率はゲーム内バランス用の数値で、実際のマッチング成功率・統計値ではありません。会話履歴や設定のサーバー同期は未実装です。


## 会話の深さ評価
- 表面層：趣味・休日・最近の出来事など、負担の少ない話題
- 中間層：好きになったきっかけ・仕事観・人柄・価値観
- 深層：恋愛観・将来像・家族観・悩みなど、信頼関係を要する話題
- 深い話題を早く出すほど高評価にはせず、会話の往復や信頼の蓄積を考慮します。初期実装はキーワード判定のため、会話文脈の理解は限定的です。

## 参考動画
アプリ内「参考動画」ページから動画URL・タイトル・カテゴリ・メモを追加できます。現状はブラウザ内メモリに保持するデモ実装です。
